Bem-vindo ao repositório do **Projeto do Ramo Estudantil IEEE do Cefet - RJ / Maracanã**!

## Sobre o Projeto

Este projeto tem como objetivo promover atividades acadêmicas, técnicas e sociais relacionadas à engenharia, tecnologia e inovação, integrando estudantes do Cefet/RJ ao universo IEEE.

## Funcionalidades

- Portal para divulgação de eventos e notícias
- Área para membros e colaboradores
- Integração com redes sociais
- Recursos para organização de workshops e palestras

## Tecnologias Utilizadas

- React.js
- JavaScript
- Node.js
- CSS

## Como Rodar o Projeto

1. Clone este repositório:
    ```bash
    git clone https://github.com/seu-usuario/seu-repositorio.git
    ```
2. Instale as dependências:
    ```bash
    npm install
    ```
3. Inicie o servidor de desenvolvimento:
    ```bash
    npm start
    ```

## Contribuindo

Contribuições são bem-vindas! Sinta-se à vontade para abrir issues ou enviar pull requests.

### Regras para Branches e Pull Requests

- Sempre crie uma branch a partir da `main` para desenvolver novas funcionalidades ou correções.
- Nomeie as branches de forma descritiva, por exemplo: `feature/nome-da-funcionalidade` ou `fix/descricao-do-bug`.
- Antes de abrir um Pull Request (PR), certifique-se de que seu código está atualizado com a branch `main`.
- Descreva claramente as alterações realizadas no PR.
- Aguarde a revisão e aprovação antes de realizar o merge.
